# 11: Keep the inbox clean: archive Messages, delete several at once

**What to build:** The owner keeps the inbox short. A Message worth keeping is moved to the Archive, where it stays stored and searchable and can be moved back; junk is deleted. Archiving is one Message at a time. Deleting can also be done in bulk: the owner switches the list into selection, ticks Messages (or all those currently listed, so a search or SIM filter can narrow it first), and deletes them after confirming.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] A Message can be archived and moved back to the inbox
- [x] The inbox lists only Messages that are not archived; the Archive lists only archived ones
- [x] Search and the SIM filter work in both
- [x] Archiving does not change whether or when a Message is forwarded
- [x] Several selected Messages are deleted in one action, after a confirmation step
- [x] "Select all" selects only the Messages currently listed
- [x] Existing databases are upgraded with every Message in the inbox
