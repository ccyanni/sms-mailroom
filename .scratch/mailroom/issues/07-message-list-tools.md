# 07: Find, delete and follow Messages on the web page

**What to build:** The Message list becomes usable day to day, mostly from a phone. The owner can filter by SIM, search Message text, and permanently delete a single Message. The page refreshes itself every few seconds so new Messages appear without reloading, and the layout reads well on a phone screen.

**Blocked by:** 01

**Status:** done

- [x] The list can be filtered to one SIM
- [x] Message text can be searched, including Chinese text
- [x] A single Message can be deleted, and deletion is permanent
- [x] New Messages appear within a few seconds without a manual reload, and the refresh keeps the current filter and search
- [x] The page is readable and operable on a phone-width screen with no horizontal scrolling
